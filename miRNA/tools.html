microRNA Tools

Feel free to use the following microRNA analysis tools. Secondary structure prediction is done by ViennaRNA package and multiple sequence alignment is done by ClustalW. These tools are using data from miRBase.

 

 microRNA family sequence alignments and conserved secondary structure prediction

     * http://hurlab.med.und.edu/cgi-bin/miRNA/miRNA.cgi

 

 microRNA individual sequence secondary structure prediction

     * http://hurlab.med.und.edu/cgi-bin/miRNA/miRNAsingle.cgi

 

 microRNA BLAST search

     * http://hurlab.med.und.edu/cgi-bin/miRNA/blast.cgi
