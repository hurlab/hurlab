Developed Tool

    * PubChemSR (Search and Retrieve)

    • PubChemSR (Search and Retrieve) is a MS-Windows-based data search and retrieval tool for NCBI's chemical databases PubChem.
    • Users can perform text search against any of the three PubChem databases
      (PubChem Compound, PubChem Substance,and PubChem Bioassay) with simple search terms
    • Bulk-download is also supported by using a set of UIDs.
      • PubChemSR is written in MS Visual Basic .Net and implemented by using Entrez Eutilities via SOAP (Simple Object Access Protocol).
      • It's tested only on Windows XP but it should work well on any other Windows platform.
      • Users must have the accompanying manual document (PDF) in the same directory with PubChemSR program in order to access from the help menu.
      • Refer to the user's manual for more details.
